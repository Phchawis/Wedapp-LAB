## 1. วัตถุประสงค์

กำหนดวิธีสำรอง เก็บรักษา และกู้คืนข้อมูลของระบบสารสนเทศห้องปฏิบัติการ
เพื่อให้ข้อมูลไม่สูญหายและกู้คืนได้ภายในเวลาที่ยอมรับได้เมื่อเกิดเหตุขัดข้อง

## 2. ขอบเขต

ครอบคลุมระบบที่ติดตั้งบนเครื่องแม่ข่ายของฝ่ายสหเวชศาสตร์

| ระบบ | ข้อมูลที่สำรอง | ทดสอบกู้คืนอัตโนมัติ |
|---|---|---|
| ทะเบียนเอกสารคุณภาพ (Masterlist) | ฐานข้อมูล + ไฟล์แนบเอกสาร | มี |
| ห้องปฏิบัติการเทคนิคการแพทย์ (Lab QMS) | ฐานข้อมูล + ไฟล์แนบเอกสาร | มี |
| ระบบควบคุมคุณภาพ (Lab QC) | ฐานข้อมูล | มี |
| ทะเบียนบุคลากร | ฐานข้อมูล + ไฟล์แนบ (เข้ารหัสก่อนส่งออก) | **ยังไม่มี — ต้องทดสอบด้วยมือ** |

## 6. วิธีปฏิบัติ

### 6.1 การสำรอง (อัตโนมัติ)

ระบบทำงานเองตามกำหนดเวลา ไม่ต้องมีผู้ปฏิบัติ ขั้นตอนที่ระบบทำ

1. สำรองฐานข้อมูลเป็นไฟล์บีบอัด
2. ตรวจว่าเชื่อมต่อที่เก็บนอกสถานที่ได้
3. ส่งฐานข้อมูลขึ้นที่เก็บนอกสถานที่ตามรอบรายวัน/สัปดาห์/เดือน
4. ซิงก์ไฟล์แนบเฉพาะที่เปลี่ยนแปลง โดยย้ายไฟล์ที่ถูกลบหรือแก้ไปเก็บในโฟลเดอร์ลงวันที่
5. ลบสำเนาเก่าในเครื่อง **เฉพาะเมื่อรอบนั้นสำเร็จทุกขั้น**
6. หากมีขั้นใดล้มเหลว ส่งอีเมลแจ้งผู้ดูแลระบบทันที

**มาตรการป้องกันความผิดพลาด**

- ไม่ซิงก์เมื่อต้นทางว่างเปล่า (ป้องกันสำเนานอกสถานที่ถูกลบตาม)
- หยุดและแจ้งเตือนหากรอบใดจะต้องลบไฟล์เกิน 20 รายการ

### 6.2 การตรวจสอบประจำเดือน (อัตโนมัติ)

ทุกวันที่ 1 เวลา 03:30 น. ระบบจะ

1. กู้ฐานข้อมูลจากไฟล์สำรองล่าสุดลงฐานข้อมูลชั่วคราว
2. เทียบจำนวนข้อมูลกับระบบจริง
3. ดึงไฟล์จากที่เก็บนอกสถานที่กลับมาตรวจว่าไม่เสียหาย
4. บันทึกผลขึ้นที่เก็บนอกสถานที่เป็นหลักฐาน
5. ส่งอีเมลแจ้งเมื่อพบปัญหา

**ผู้ดูแลระบบต้องตรวจผลและรายงานหัวหน้างานทุกเดือน**

> ระบบทะเบียนบุคลากรยังไม่มีการทดสอบกู้คืนอัตโนมัติ เนื่องจากไฟล์สำรองถูกเข้ารหัส
> ต้องทดสอบด้วยมืออย่างน้อยปีละ 1 ครั้ง และเป็นโอกาสตรวจสอบว่ารหัสถอดรหัสยังใช้ได้

### 6.3 การกู้คืนกรณีฉุกเฉิน

**ขั้นที่ 1 — ประเมินสถานการณ์และแจ้งหัวหน้างาน** ก่อนดำเนินการใด ๆ

**ขั้นที่ 2 — กู้ฐานข้อมูล**

```
gunzip -c <ไฟล์สำรอง>.sql.gz | docker exec -i masterlist-db-1 psql -U <ผู้ใช้> -d <ฐานข้อมูล>
```

**ขั้นที่ 3 — กู้ไฟล์แนบ**

```
rclone copy gdrive:TUH-Backup/<ระบบ>/files/ <โฟลเดอร์ปลายทาง>/
```

**ขั้นที่ 4 — ตรวจสอบ** จำนวนเอกสาร ผู้ใช้งาน และไฟล์แนบ ว่าตรงกับก่อนเกิดเหตุ

**ขั้นที่ 5 — บันทึกเหตุการณ์** ลงบันทึกความไม่สอดคล้อง ระบุสาเหตุ สิ่งที่ทำ
และข้อมูลที่สูญหาย (ถ้ามี) พร้อมแนวทางป้องกันการเกิดซ้ำ

> **กรณีเครื่องแม่ข่ายเสียหายทั้งเครื่อง** ต้องติดตั้งระบบใหม่ก่อน แล้วจึงกู้ข้อมูล
> จากที่เก็บนอกสถานที่ — ต้องใช้รหัสเข้าบัญชี Google และรหัสถอดรหัส (สำหรับข้อมูลบุคลากร)
